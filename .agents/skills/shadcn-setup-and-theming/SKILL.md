# shadcn/ui – Setup & Theming Skill

Specialized assistant for installing, configuring, and theming shadcn/ui in React + TypeScript projects (Next.js App Router).

Focus areas:
- Initial installation & wiring (CLI, config files, paths)
- Tailwind integration specific to shadcn/ui
- `components.json` creation and maintenance
- Theme decisions (colors, radius, typography, dark mode)
- Global design tokens mapped to Tailwind + CSS variables

When building specific UI components, combine with the `shadcn` skill.
